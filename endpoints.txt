visual-anomaly-inspection-api — Endpoints
==========================================

GET /
  api_name, status, message, docs_url, health_url, metadata_url, predict_url

GET /health
  status: ready | loading | error
  model_loaded, profiles_loaded, thresholds_loaded, bbox_config_loaded
  supported_categories_count: 7
  device: cpu | cuda
  error (when startup validation fails)

GET /metadata
  api_name, experiment_name, model_name, supported_categories
  image_size: 256, score_name, outputs, localization_method, note

POST /predict  (multipart)
  file, category, include_images=true, include_debug=false, include_overlay=false

POST /infer  (legacy, deprecated — query category)

Port: 7860 (Hugging Face Spaces / Docker)
CORS: CORS_ORIGINS env (default *)
